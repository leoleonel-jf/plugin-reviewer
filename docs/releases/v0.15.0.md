# Plugin Reviewer v0.15.0

Three outputs stop surprising you. These are three medium findings of the independent review of
2026-11-20, about what the tool overwrites, what a failed update costs, and what a local build
touches.

## What changes for you

- **`build` and `lock --out` replace only what has their own shape.** The file at `--out` must
  have the whole structure of a dashboard page or of a lockfile this tool writes, as every
  released version wrote them; a document that quotes the format, even a valid island, is
  refused. A link at `--out` is refused. `--force` replaces an unrecognized file in both commands,
  and a link is then replaced by a regular file, never written through; a directory is refused
  even with `--force`. The lockfile is now written atomically.
- **A refused `update all` costs nothing.** The destination is checked before the capture: no
  baseline is appended, no ID is spent, and the summary says `refused: "output"`. If the render
  fails after the append and `build` returns its exit code, the summary names the recorded
  `baseline_id` and `failed_step: "render"`, and `dashboard.py build` renders it without a new
  capture.
- **A network project root is not contacted.** A `known_projects` root such as `\\server\share`
  is listed as not checked, decided from the text alone; local roots are checked as before. A
  mapped drive or a mount point that looks local is not recognized from its text.

## Changes

- **`ledgerlib/outputs.py`** (new): `guard_output`, the overwrite guard `build` and `lock` share;
- **`ledgerlib/build.py`**: `looks_like_dashboard`, `guard_dashboard_output`,
  `is_network_root`; `computed.unverified_projects`;
- **`ledgerlib/lock.py`**: `looks_like_lock`; atomic write; a failed write exits `2`;
- **`ledgerlib/update.py`**: the destination checked before the capture; `failed_step` in the
  summary;
- **template**: the overview and the project list show unverified roots;
- **references**: `DASHBOARD.md`, `LEDGER_INTEGRITY.md`; `skills/dashboard/SKILL.md` reports the
  new summary states;
- **tests**: new classes in `test_build.py`, `test_lock.py`, `test_update.py` and
  `test_shell.py`; each guard proved by ablation.

New fields are optional and additive. No identifier, label or required field changed.
